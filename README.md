# 🌍 **Triftmap - Marketplace Thrift Berbasis GIS & Kurasi Kualitas**

*Menghubungkan keberlanjutan, teknologi, dan ekonomi sirkular dalam satu platform.*

Triftmap adalah platform marketplace berbasis web yang dirancang khusus untuk perdagangan barang thrift atau bekas. Dengan memadukan teknologi **Geographic Information System (GIS)** dan sistem **kurasi kualitas terpusat**, Triftmap hadir sebagai solusi nyata untuk mengurangi limbah tekstil sekaligus membuka peluang ekonomi baru bagi masyarakat.

Di tengah meningkatnya masalah limbah tekstil di Indonesia, Triftmap mengajak masyarakat beralih dari pola konsumsi *"beli–pakai–buang"* menuju gaya hidup *"beli–pakai–salurkan"*. Melalui pendekatan berbasis lokasi dan kurasi profesional, Triftmap tidak hanya memudahkan proses jual beli barang thrift, tetapi juga menggerakkan perubahan sosial menuju lingkungan yang lebih hijau dan berkelanjutan.

---

## ✨ **Visi & Misi**

### 🎯 **Visi**

Menjadi platform thrift terpercaya di Indonesia yang mempercepat ekonomi sirkular melalui teknologi web yang efisien dan ramah lingkungan.

### 🔧 **Misi**

Triftmap dibangun di atas tiga pilar utama:

* 🌱 **Green Growth**
  Mengurangi limbah tekstil nasional dengan memperluas akses pasar untuk barang layak pakai.

* 🤝 **Inclusive Growth**
  Memberdayakan UMKM thrift, komunitas reseller, hingga individu penjual untuk ikut merasakan manfaat ekonomi digital.

* 🔍 **Trusted Quality**
  Menciptakan standar jaminan kualitas melalui kurasi profesional yang transparan dan objektif.

---

## 🛡️ **Jaminan Kualitas yang Terverifikasi**

Berbeda dari marketplace thrift pada umumnya, Triftmap menghadirkan sistem **Histori Kurasi** yang mencatat seluruh proses seleksi dan grading barang oleh tim profesional.
Setiap produk yang lolos kurasi akan mendapatkan **badge grade** seperti:

* 🟢 **Grade A**
* 🟡 **Grade B**
* 🟠 **Grade C**
* 🔴 **Grade D**

Badge ini menjadi jaminan bagi pembeli untuk mengetahui kondisi barang secara jelas — tanpa harus bergantung pada review atau rating yang subjektif.

---

## 🗺️ **Pencarian Berbasis Lokasi (GIS)**

Triftmap mengintegrasikan peta interaktif berbasis GIS untuk memudahkan pengguna menemukan barang thrift di sekitar mereka.
Keunggulannya:

* Mengurangi waktu & biaya pengiriman
* Menekan jejak karbon dari pengiriman jarak jauh
* Menyediakan pengalaman belanja yang lebih personal melalui algoritma **“Near You Picks”**

---

## 📊 **Dashboard Penjual yang Transparan**

Untuk para penjual, Triftmap menyediakan dashboard lengkap untuk:

* Mengelola inventaris
* Melihat status kurasi barang
* Memantau performa penjualan
* Melacak histori kualitas

Semua dibuat transparan agar penjual dan pembeli sama-sama merasa aman dan nyaman.

---

## 🏆 **Sistem Gamifikasi & Komunitas**

Setiap transaksi di Triftmap memberikan **EXP** sebagai bentuk kontribusi pengguna dalam menyelamatkan bumi dari limbah tekstil.
Pengguna bisa naik level dan mendapatkan badge seperti:

* ⭐ **Top 1% Contributor**
* 🏅 **Sustainability Hero**
* 🌿 **Eco Level Up**

Semuanya dirancang untuk membuat proses berkontribusi menjadi lebih menyenangkan dan bermakna.

# 🚀 **Panduan Instalasi & Menjalankan Proyek (Next.js)**

Proyek Triftmap dibangun menggunakan [Next.js](https://nextjs.org) dan dibuat dengan [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## 📥 1. Clone Repository

Clone proyek ke komputer Anda:

```bash
git clone https://github.com/tiara082/thirftmap.git
```

Masuk ke folder proyek:

```bash
cd thriftmap
```

## 📦 2. Instal Dependensi

Gunakan package manager favorit Anda:

```bash
npm install
# atau
yarn install
# atau
pnpm install
# atau
bun install
```

## ▶️ 3. Menjalankan Server Development

Untuk menjalankan aplikasi:

```bash
npm run dev
# atau
yarn dev
# atau
pnpm dev
# atau
bun dev
```

Akses di browser:

👉 **[http://localhost:3000](http://localhost:3000)**
